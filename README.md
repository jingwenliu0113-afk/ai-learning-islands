# AI 學習群島

一個用來準備 **AI 工程師面試**的 3D 練習遊戲。操作小人坐船到八座領域島，每一堂課是島上的一個地點：先上課、再闖關，最後打敗「面試官」Boss。答錯的題目會變成蟲，該複習的題目會長成雜草。

**▶ 直接玩：<https://jingwenliu0113-afk.github.io/ai-learning-islands/>**

不用安裝、不用註冊，用電腦或手機的瀏覽器打開就能玩。

---

|---|---|

## 玩法

- **先上課，再闖關**：每堂課先跟領航員小星上一堂小課（有不扣分的小測驗），再挑戰關卡拿星星，最後一關是 Boss「面試官」。
- **錯誤會變成蟲**：答錯會冒出一隻蟲，之後答對同一題就能抓到，收進蟲蟲圖鑑。每種蟲代表一種常見的錯誤。
- **雜草就是該複習了**：答過的題目會在 1、3、7、21 天後回來（間隔複習），到時候島上會長雜草。
- **航海圖**：3D 六角群島地圖，每堂課是一格島，島上的建築從木牌、鷹架、小屋長成地標，一眼看出哪裡還沒學。點島就能出航。
- **學越多頭越大**：答對過的題越多，角色的頭越大，全部答對是 2.5 倍。
- **AI 助教（選用）**：接上 Google Gemini（預設 Gemini 4 Hydrogen），可以問課程問題、請 AI 解釋剛剛答錯的題目、幫面試口述題評分。設定方式見下面。
- 每日任務、連續天數、金幣、打扮、建造自己的小島、白天與夜晚。

## AI 助教（Gemini）怎麼開

AI 助教要用**你自己的** Google Gemini API 金鑰。遊戲本身沒有金鑰，也沒有後端伺服器。

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 按「Create API key」。也可以在 Google Cloud Console 的專案裡啟用「Generative Language API」，再到「API 和服務 → 憑證」建立 API 金鑰。
2. 回到遊戲，按右上角「🤖 AI 助教」→ 貼上金鑰 →「儲存並測試」。
3. 想換模型就按 ⚙ 改模型名稱（預設 `gemini-4-hydrogen`）。

**金鑰的安全**

- 金鑰只存在你這台電腦的這個瀏覽器（localStorage），從瀏覽器直接送到 Google，不會經過其他伺服器，也不會跟著「匯出存檔」一起匯出。
- 在公用電腦上使用時，不要勾「記住金鑰」，用完按「清除金鑰」。
- 建議到 Google Cloud Console 把金鑰的「API 限制」設成只能用 Generative Language API，並設定預算提醒。
- 用量照 Google 的價格計算，免費額度用完後可能會收費。

AI 的回答可能有錯，跟課程內容不一致時以課程為準。

## 進度存在哪裡

進度存在瀏覽器裡（localStorage），不會上傳到任何地方。換電腦、換瀏覽器或清除瀏覽器資料，進度就會不見。「設定 → 匯出存檔」可以下載成 `.json`，換電腦時再匯入。

## 離線玩

## 技術

純前端：HTML、CSS、JavaScript，3D 用 [three.js](https://threejs.org/) r149。不需要建置，也沒有後端。

```
index.html          入口
css/style.css       介面樣式
js/store.js         題庫資料模型、存檔、間隔複習
js/world.js         3D 島嶼世界、主角移動、鏡頭、渡船
js/chart.js         航海圖（3D 六角群島）
js/avatar.js        角色、蟲、頭像
js/quiz.js          七種題型、闖關、結算
js/lesson.js        上課流程
js/gemini.js        AI 助教（Gemini API）
js/ui.js            畫面上的面板、選單、設定
data/content.js     題庫（78 堂、1349 題）
```
