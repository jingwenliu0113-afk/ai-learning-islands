# AI 學習群島

一個用來準備 **AI 工程師面試**的 3D 練習遊戲。操作小人坐船到九座領域島，每一堂課是島上的一個地點：先上課、再闖關，最後打敗「面試官」Boss。答錯的題目會變成蟲，該複習的題目會長成雜草。

**▶ 直接玩：<https://jingwenliu0113-afk.github.io/ai-learning-islands/>**

不用安裝、不用註冊，用電腦或手機的瀏覽器打開就能玩。

## 玩法

- **先上課，再闖關**：每堂課先跟領航員小星上一堂小課（有不扣分的小測驗），再挑戰關卡拿星星，最後一關是 Boss「面試官」。
- **錯誤會變成蟲**：答錯會冒出一隻蟲，之後答對同一題就能抓到，收進蟲蟲圖鑑。每種蟲代表一種常見的錯誤。
- **雜草就是該複習了**：答過的題目會在 1、3、7、21 天後回來（間隔複習），到時候島上會長雜草。
- **航海圖**：3D 六角群島地圖，每堂課是一格島，島上的建築從木牌、鷹架、小屋長成地標，一眼看出哪裡還沒學。點島就能出航。
- **AI 面試官 Boss**：Boss 關可以讓 Gemini 扮演面試官，看你的回答追問兩次，最後打 0–100 分並指出漏洞。
- **釣魚**：走到碼頭盡頭甩竿，浮標沉下去就拉竿，題目會出現在畫面下方，答對才釣得起來。越稀有的魚越難，共 27 種。
- **島上小遊戲**：我的小島的遊戲機台有翻牌配對和 60 秒快問快答。
- **冒險**：坐船時遇到海怪或漂流瓶、每座島每天藏一個寶箱（答對才打得開）、每座島的島民會給支線任務。
- **稀有裝扮**：海盜帽（寶箱）、漁夫帽（傳說魚）、鸚鵡（島民任務）。
- **學越多頭越大**：答對過的題越多，角色的頭越大，全部答對是 2.5 倍。
- **AI 助教（選用）**：接上 Google Gemini，可以問這堂課的問題、請 AI 解釋剛剛答錯的題目、幫面試口述題評分。設定方式見下面。
- 每日任務、連續天數、金幣、打扮、建造自己的小島、白天與夜晚。

## 用手機玩

- 直式、橫式都可以玩，航海圖在直式畫面會自動轉向，整張群島都放得下。
- 用 LINE 點開連結時，遊戲是在 LINE 的內建瀏覽器裡跑，**進度也存在那裡**。想固定用 Safari 或 Chrome 玩，先按右上角選單的「用預設瀏覽器開啟」，之後都從同一個瀏覽器進來。
- 看到畫面怪怪的（題目被切掉、按鈕跑掉），先重新整理一次；還是一樣的話，截圖告訴作者是用什麼手機、什麼瀏覽器。

## AI 助教（Gemini）怎麼開

按右上角「🤖 AI 助教」，有兩種連法：

**用分享的額度（朋友）**：輸入遊戲作者私下給你的**通行碼**就能用，每人每天有次數上限。問題會經過作者的中繼站（Google Apps Script）送到 Gemini，金鑰在中繼站裡，任何人都看不到；遊戲檔案和這個 repo 裡都沒有金鑰。請不要在 AI 助教裡輸入個資。

**用自己的金鑰**：

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 按「Create API key」。也可以在 Google Cloud Console 的專案裡啟用「Gemini API」（以前叫 Generative Language API），再到「API 和服務 → 憑證」建立 API 金鑰。
2. 回到遊戲，按「🤖 AI 助教」→ ⚙ →「用自己的金鑰」→ 貼上金鑰 →「儲存並測試」。
3. 想換模型就改模型名稱（預設 `gemini-4-hydrogen`）。

**自己的金鑰的安全**

- 金鑰只存在你這台電腦的這個瀏覽器（localStorage），從瀏覽器直接送到 Google，不會經過其他伺服器，也不會跟著「匯出存檔」一起匯出。
- 在公用電腦上使用時，不要勾「記住金鑰」，用完按「清除金鑰」。
- 建議到 Google Cloud Console 把金鑰的「API 限制」設成只能用「Gemini API」，並設定預算提醒。
- 用量照 Google 的價格計算，免費額度用完後可能會收費。

AI 的回答可能有錯，重要的觀念請再查證。

## 進度存在哪裡

進度存在瀏覽器裡（localStorage），不會上傳到任何地方。換電腦、換瀏覽器或清除瀏覽器資料，進度就會不見。「設定 → 匯出存檔」可以下載成 `.json`，換電腦時再匯入。

## 離線玩

按這個頁面上方的 **Code → Download ZIP**，解壓縮後雙擊 `index.html` 就能玩，不需要網路（AI 助教除外）。

## 技術

純前端：HTML、CSS、JavaScript，3D 用 [three.js](https://threejs.org/) r149。不需要建置，也沒有後端。

```
index.html          入口
css/style.css       介面樣式
js/store.js         題庫資料模型、存檔、間隔複習
js/world.js         3D 島嶼世界、主角移動、鏡頭、渡船
js/chart.js         航海圖（3D 六角群島）
js/play.js          釣魚、翻牌配對、快問快答、航行事件、寶箱、島民任務
js/interviewer.js   AI 面試官 Boss
js/avatar.js        角色、蟲、頭像
js/quiz.js          七種題型、闖關、結算
js/lesson.js        上課流程
js/gemini.js        AI 助教（Gemini API：分享的額度或自己的金鑰）
js/config.js        分享額度的中繼站網址（只有網址，沒有金鑰）
js/ui.js            畫面上的面板、選單、設定
js/sound.js         音效（用 Web Audio 即時合成，沒有音檔）
js/main.js          啟動：讀存檔、建立 3D 世界、介面與小遊戲
data/content.js     題庫（79 堂、1387 題）
```
